# Wenjin Wang — Resume & Portfolio

A responsive, blue-and-white personal portfolio. Built with plain HTML, CSS and JavaScript; no dependencies or build step.

## Preview locally

From this directory, run `python -m http.server 8765 --bind 127.0.0.1`, then open [the local preview](http://127.0.0.1:8765). You can also open `index.html` directly.

## Files

- `index.html`: English content, Chinese translations and semantic sections.
- `styles.css`: responsive layout, keyboard focus and reduced-motion support.
- `script.js`: progressive enhancements for language and navigation.
- `assets/`: optimised images from the author's existing projects and a small SVG favicon.
